Started as a Figma design system on 22 October 2023, before ever
becoming code. The goal was to work out a small, opinionated set of
type, color, and spacing rules first — then build a Hugo theme that
implements them faithfully, rather than the usual other way around.

This site runs on it directly, vendored in as a submodule so the theme
and the content it renders can evolve independently.
